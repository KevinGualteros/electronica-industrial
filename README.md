# Electrónica industrial

Proyecto académico sobre conectividad entre dispositivos y sistemas de control
industrial. Aborda la comunicación IP, el intercambio de datos mediante Modbus
TCP/IP y la integración de PLC y HMI, relacionando los fundamentos de redes con
la automatización y las tecnologías operacionales (OT).

## Contenido del repositorio

- `Documentación Técnica.pdf`: documento de referencia del proyecto.
- `Video General.mp4`: presentación audiovisual general.
- `proyectofinaleleinparte1.auto.sta`
- `proyectofinaleleinparte1.stu`
- `proyectofinaleleinparte1.ztx`

Los tres últimos archivos son materiales auxiliares del proyecto. Su apertura o
edición puede requerir la aplicación que los generó; consulta la documentación
para identificar el entorno compatible.

## Consulta

Para conocer el contexto, empieza por la documentación técnica y luego revisa
el video. Se requiere un lector de PDF y un reproductor compatible con MP4.
Este repositorio contiene documentación y archivos del proyecto; no incluye una
guía de instalación de un sistema desplegable.
